This part of the documentation highlights some of the functionality in Alvaldi:

* [Terminal](/features/terminal) - For investigating and fixing issues by running commands on remote devices.
* [Inventory](/features/inventory) - To see important context and information about the device you're troubleshooting.
* [Device list](/features/device-list) - To find the device(s) you are interested in, using search, groups, and filters.
* [File transfer](/features/file-transfer) - Uploading and downloading files complements your commands in the terminal. 
* [Audit log](/features/audit-log) - For seeing who did what, when.
* [Session playback](/features/session-playback) - To replay the commands a user ran, showing both input keystrokes as well as command output.
* [RBAC](/features/rbac) - For managing what different users in your organization have access to.
