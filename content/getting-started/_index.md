Alvaldi provides easy to use, secure, and efficient remote troubleshooting for connected devices.
This getting started tutorial series will help you set up and use Alvaldi for the first time.
There are 4 parts to the getting started tutorials:

1. [Introduction.](/getting-started/introduction)
2. [Setup.](/getting-started/setup)
3. [Connecting with the terminal.](/getting-started/connecting-with-the-terminal)
4. [Transferring files.](/getting-started/transferring-files)

It should be read in that order, so when you're ready, start at [the introduction](/getting-started/introduction).
