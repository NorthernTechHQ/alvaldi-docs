Once you have Alvaldi set up and installed on your devices, you can start using it.

Open up the web application at [app.alvaldi.com](https://app.alvaldi.com) and log in if you haven't already.

From the device list you can look for a device you'd like to access:

{{< wideimg "/screenshot-gui-all-devices.png" "Screenshot of the Alvaldi GUI, showing a list of all devices">}}

(The search bar at the top of the screen can also help you find the device you're looking for).

Clicking on **View details** on one of the devices takes you to that device's page:

{{< wideimg "/screenshot-gui-device-info-page.png" "Screenshot of the device info page of Alvaldi's GUI, with a terminal which is not yet connected">}}

On the right hand side, you have [**Inventory**](/features/inventory) and **Identity** information about the device.
The terminal and the file transfer sections on the left side will help you access the device and troubleshoot issues.
As an example, we can click **Connect Terminal** to connect the terminal and run the echo command to see that everything works as expected:

{{< wideimg "/screenshot-gui-device-info-page-hello-world.png" "Screenshot of the terminal in Alvaldi's GUI, with a hello world command as an example">}}
