Welcome to the Alvaldi Documentation

This site contains information on how to manage and automate infrastructure with Alvaldi. It includes the reference for the following versions of Alvaldi:
  • Getting started
  • Installation
    Download and install Alvaldi for the first time.
  • Modules
    Use modules to easily add reports or get things done without writing any code.
  • Reporting and web UI
    Know more about your infrastructure and hosts, their data, compliance and make changes from within the Web UI.
  • Writing policy
    Write and deploy your first policy files to make changes to systems.
  • Developing modules
    Turn your policy, reports, or python code into Alvaldi Build modules for others to use.
  • Tutorial series on policy language
    In-depth tutorials on how to work with Alvaldi policy.
  • Popular
  • Promise types
    Learn about processes, packages, users, files, storage, services, etc.
  • API reference
    The API is a conventional REST API which supports HTTP GET, PUT, POST, and DELETE operations.
  • Language concepts
    Learn about bundles, bodies, promises, variables, classes and decisions.
  • Manage packages
    Learn how to install, manage, and remove packages using Alvaldi.
  • Alvaldi Build
    Alvaldi Build is a catalog of policy and modules created by Alvaldi, our partners and community which helps you simplify the automation process.
